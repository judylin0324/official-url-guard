# 官網守門員

> 網頁可以做得跟官方一模一樣，但網址騙不了人。

假冒停車費、交通罰單、ETC 通行費、包裹運費、運動幣、健康幣、抽獎、點數到期、假投資……這些詐騙網頁做得很像真的，但看網址就知道是假的。官網守門員替你看網址，並在你**付款、轉帳或輸入驗證碼之前**擋下來。

- 原始碼與問題回報：<https://github.com/judylin0324/official-url-guard>
- 手機版簡訊檢查網頁：<https://judylin0324.github.io/official-url-guard/>（啟用 GitHub Pages 後）
- 隱私權政策：<https://judylin0324.github.io/official-url-guard/privacy.html>

包含兩個部分：

| | 用在哪裡 | 能做什麼 |
|---|---|---|
| **Chrome／Edge 擴充功能**（本資料夾） | 電腦 | 自動攔截、付款頁防護、右鍵檢查、一鍵通報 |
| **簡訊檢查網頁**（`web/index.html`） | 手機、任何瀏覽器 | 貼上簡訊、LINE 訊息或 Email，不用點開就能檢查 |
| **簡訊、通訊軟體網頁版**（擴充功能內建） | 電腦 | 自動檢查 Google 訊息網頁版（Android 簡訊）、Messenger、Telegram、WhatsApp 網頁版裡對方傳來的訊息 |
| **Gmail 收件匣過濾**（`gmail/`） | Gmail（任何裝置） | 在你自己的 Google 帳號裡每 10 分鐘檢查新信，詐騙信移出收件匣 |

## 五道防線

| 時機 | 做什麼 |
|---|---|
| **1. 點開前** | 工具列視窗、右鍵選單「檢查這個連結」、手機版網頁：貼上整段簡訊，比對「訊息自稱是誰」和「連結實際網址」。例如簡訊自稱監理服務網，連結卻不是 `mvdis.gov.tw`，就判為危險。 |
| **2. 連線前** | 165 涉詐網域與自訂封鎖清單用瀏覽器內建規則（declarativeNetRequest）攔截，**請求根本不會送到詐騙網站**。其他仿冒網址也會先顯示警告頁，例如 `ctbc-bank.top`、`www.mvdis.gov.tw.pay-fine.top`、`mvdis-gov-tw.cc`、`shoppe-tw.com`、`7-11-myship.com`，以及用西里爾字母假冒的 `аpple.com`。 |
| **3. 網頁打開後** | 比對網頁「自稱是誰」和「要你做什麼」。網址不是它自稱的機構，就跳出全頁警告，並告訴你真正的官方網址。 |
| **4. 送出前** | 在不在官方清單的網站送出信用卡號前（或在可疑網站送出簡訊驗證碼前），先跳出確認畫面，標明「你正要把卡號送給哪個網站」。 |
| **5. 發現詐騙時** | 一鍵通報：開啟數位發展部「網詐通報查詢網」，自動填入可疑網址，完整說明也會複製到剪貼簿；同時把網頁截圖存到下載資料夾當證據。 |

### 「要你做什麼」包含

- 信用卡號、安全碼、有效期限。另外，你打字的內容一旦通過信用卡號檢查碼，就算欄位沒有任何標示也會警告。
- 銀行帳號、網銀帳密、簡訊驗證碼、身分證字號（打字時用檢查碼判斷，內容不會離開網頁）。
- 頁面上的轉帳或匯款帳號（ATM、銀行代碼寫法）、超商繳費代碼、USDT 等加密貨幣錢包地址。
- 要你下載 APK 安裝檔。
- 網頁程式把資料直接傳到 Telegram 機器人或 Discord（詐騙套件常見做法）。
- 「保證獲利」「穩賺不賠」搭配加 LINE 或 Telegram（假投資導流頁）。新聞或防詐宣導頁在報導這些字眼時不會誤判。
- 假投資平台要你「先繳稅金、保證金才能出金」。
- 一頁式購物頁：只能貨到付款、限時搶購，卻找不到公司統編或地址（假網拍是 165 受理件數最多的詐騙）。

### 專門對付仿冒繳款網頁

假停車費、假罰單、假 ETC、假補運費頁面做得和官網幾乎一樣，有時連機構名稱都做成圖片，讀不到文字。除了比對網址，還會看這些地方：

| 線索 | 怎麼判斷 |
|---|---|
| **抄襲官網的痕跡** | 很多假網頁是整頁複製官網，原始碼還留著官網的正式網址（`canonical`、`og:url`、`<base>`），或直接從官網載入 Logo、樣式表、程式。就算頁面上一個機構名稱都讀不到，也知道它在冒充誰。政府網站常見的無障礙標章、商店結帳頁上的支付品牌 Logo（台灣 Pay、街口…）不算。 |
| **偷傳卡號** | 詐騙套件常在你打字時就把卡號傳給詐騙集團，好立刻盜刷。官網守門員在網頁裡比對：你剛輸入的卡號，有沒有在你**按下送出之前**就被傳出去（`fetch`、`XMLHttpRequest`、`sendBeacon`、`WebSocket`、圖片網址夾帶，含 base64 編碼）。只在記憶體裡比對，回報的只有「傳到哪個網站」。送到綠界、TapPay、Stripe 這類正規金流換成代碼，或常見的網站分析工具，不算偷傳。 |
| **正規金流 vs 自製刷卡表單** | 正規商店的刷卡欄位放在綠界、藍新、TapPay、Stripe 等金流服務的框架裡，卡號不經過商店網站。卡號直接輸入在網站自己做的表單裡，會列為可疑線索之一。 |
| **假的 3D 驗證頁** | 頁面寫著「3D 驗證」「Verified by Visa」「SecureCode」「J/Secure」，要你輸入簡訊驗證碼，網址卻不是發卡銀行或驗證服務商。 |
| **小額誘餌** | 停車費、補運費只要幾十、一百多元，讓人不設防地輸入卡號；卡號外流後被拿去盜刷大額。300 元以下的繳費名目搭配卡號欄位會加重判斷。 |
| **新註冊的網域** | 警告畫面、提示列、工具列視窗都有「查註冊日期」按鈕，按了才查（只把網域名稱送到 rdap.org）。才註冊幾天、幾十天的網站會明白標出來，之後再進同一個網站會直接在連線前攔截。 |
| **Logo 圖片比對** | 網站圖示（favicon）或頁首 Logo 和官網的一模一樣，網域卻不同。GitHub Actions 每週打開官方網站首頁，算出圖示與 Logo 的圖片指紋，發布到專案網站，插件每天下載。要你付款或輸入密碼的網頁才會比對；只有 Logo 一樣（例如新聞、介紹文章）不加分。不同機構共用的圖示（網站平台預設圖示）會剔除，政府網站共用的圖示（例如國徽）視為「政府網站」。 |
| **QR Code** | 解開網頁上的 QR Code（圖片、canvas、SVG 都可以）：連到仿冒網址的，照網址判斷；台灣 Pay（TWQR）、行動支付付款碼（會讀出收款方與金額）、虛擬貨幣錢包，算成「要你付款或轉帳」；LINE 加好友會比對 165 詐騙 LINE ID。冒名停管處、只放一個轉帳 QR Code 的假繳費頁也抓得到。 |
| **裝置端 AI 判讀（實驗功能）** | 網頁要你付款或輸入密碼、關鍵字卻看不出它自稱是誰時，請 Chrome 內建的 AI 模型（Gemini Nano）讀一次網頁文字，找出簡稱、英文名稱這類寫法（「MEGA ICBC」→ 兆豐銀行、「北市停管」→ 臺北市停車管理工程處）。AI 說的名稱必須在網頁上找得到根據，不然不採用；AI 的判讀分數比關鍵字低。模型在你的電腦上執行，只有已經下載好才會使用。 |

警告畫面也會告訴你**這筆費用正確的繳費管道**，例如停車費 → 各縣市停管處網站、超商、行動支付 App、全國繳費網；ETC → 遠通電收官網與 App；包裹 → 中華郵政、黑貓、新竹物流官網。訊息自稱電信、銀行時，會請你到那家公司的官網查。

### 簡訊、LINE 訊息、Email

除了比對「自稱是誰」和連結網址，也會看訊息要你在連結裡做什麼。例如要你填信用卡、輸入驗證碼、登入網銀、綁定帳戶、安裝遠端工具，再加上「今晚失效」「30 分鐘內」或「免費升級」「回饋待領」這類催促或好處，就會判為危險。

Email 另外會檢查：

- **寄件人**：寄件人網域不是自稱機構的官方網域，或用 Gmail 等免費信箱自稱機構。
- **藏字**：字中間夾了看不見的零寬字元（「Andr​oid」「処‍理」），這是躲過垃圾信過濾的手法。
- **拆開的品牌名**：「lChunghwalTelecomlCo」這類在名稱裡混入字元的寫法，一樣認得出是在冒充中華電信。
- **否定句**：「請勿提供密碼」「暗証番号を求めることは一切ありません」是詐騙信照抄的安全提醒，不會被當成「要你提供」。
- **轉址連結**：Outlook Safe Links、Google 轉址、Facebook 外部連結、Proofpoint 這類「外層是官方網域、裡面藏著目的地」的連結，會拆開檢查真正的目的地。
- **電子報追蹤連結**：Benchmark Email、Mailchimp、SendGrid 等服務的點擊追蹤連結看不到最後去哪，會提醒；連結帶著識別你信箱的代碼時也會說明。
- **日文、英文**：退稅（還付金）、未納、再配達、refund、unpaid toll 等常見詐騙用語。

沒有連結的訊息也會提醒：

- 要你把驗證碼或復原碼傳給他。
- 要你先付錢才能領錢或開通。
- 要你保密、不要打電話確認。
- 要你轉帳到某個帳戶。

### 「自稱是誰」包含

- **政府機關**：停管處、監理站、交通局、國稅局、健保署、關務署（EZ WAY 易利委）等。
- **政府補助名目**：運動幣、健康幣、普發現金、振興券、租金補貼等。頁面提到這些，就等於自稱政府，網址就必須是 `.gov.tw`。
- **企業與機構**：官方清單共 446 個機構、536 個網域（含 38 個日本政府機關與常被冒用的日本品牌），包含醫院、投信投顧、遊戲點數、新聞媒體、銀行、證券、保險、郵局、電信、ETC、超商（含賣貨便）、電商、支付、航空、加密貨幣交易所。

## 燈號

| 工具列徽章 | 意思 |
|---|---|
| 綠色 ✓ | 官方網站，或 `.gov.tw`、`.edu.tw` 網域，或你信任的網站 |
| 無 | 不在官方清單，也沒有可疑特徵 |
| 橘色 ! | 有可疑特徵；或是官方平台上任何人都能建立的內容（Google 表單、LINE 加好友等） |
| 紅色 ✕ | 高度疑似詐騙 |

一般商店的結帳頁只會在頂端顯示黃色提醒（「付款前請再次確認網址」），不會整頁擋住。

## 安裝擴充功能（尚未上架，用「開發人員模式」載入）

1. 到 [Releases 下載頁](https://github.com/judylin0324/official-url-guard/releases/latest) 下載 `official-url-guard-v版本.zip`，按右鍵「解壓縮全部」，得到 `official-url-guard` 資料夾（請放在固定的地方，之後不要刪除或移動）。
2. Chrome 網址列輸入 `chrome://extensions`（Edge 為 `edge://extensions`）。
3. 打開右上角「開發人員模式」。
4. 按「載入未封裝項目」，選擇 `official-url-guard` 資料夾（有 `manifest.json` 的那一層）。
5. 點工具列的拼圖圖示，把「官網守門員」釘選出來。

## 涉詐網域清單（預設每天自動更新）

很多假投資網站取的是自己的名字，網址看不出破綻，只能靠清單攔截。

本專案每天用 GitHub Actions 把下列公開來源彙整成一份清單（`feed/blocklist.txt`，2026/11 共 31,604 筆），發布在專案網站；擴充功能與 Gmail 收件匣過濾每天下載這一份。彙整清單下載不到或超過 4 天沒更新時，會自動改成直接下載原始來源。來源下載失敗或筆數驟降時，彙整流程沿用上次成功的資料，並自動開 Issue 通知維護者。

| 來源 | 內容 | 2026/11 筆數 |
|---|---|---|
| [TWNIC 停止解析詐騙網址](https://github.com/lf94878964/Taiwan-Blocked-Domains)（社群整理，MIT 授權） | 2023/6–2026/10 通報 TWNIC 並停止解析的網域 | 1,693 |
| [165 假投資（博弈）網站](https://github.com/g0v-data/165-data)（g0v 鏡像） | 警政署 165 開放資料 | 29,929 |
| [165 假投資（博弈）網站](https://data.gov.tw/dataset/160055)（內政部官方） | 同上，官方來源只接受台灣的網路連線 | 台灣以外無法下載 |

- 清單上的網站在**送出請求前**就被攔下（瀏覽器內建的 declarativeNetRequest），連一個封包都不會送到詐騙網站。
- 所有清單都會先「淨化」：剔除官方網站、政府網域與網域後綴本身，避免清單出錯或被竄改時把 `google.com`、某個 `.gov.tw` 整個擋掉。實測下載時就剔除了 `play.google.com`。
- 也可以在設定頁手動匯入 CSV（例如 [165反詐騙諮詢專線_遭停止解析涉詐網站](https://data.gov.tw/dataset/176455)）或加入其他清單網址。手動匯入的清單和自動更新的清單分開存，不會被覆蓋。
- **詐騙 LINE ID**（選用）：匯入 165「詐騙 LINE ID」清單後，加好友連結或網頁上出現清單裡的 LINE ID 就會警告。

## 簡訊與通訊軟體網頁版（Google 訊息、Messenger、Telegram、WhatsApp）

在電腦上用這些網頁版看訊息時，插件會自動檢查畫面上**對方傳來的**每一則訊息（自己送出的不檢查）：

| 網站 | 檢查什麼 |
|---|---|
| [Google 訊息網頁版](https://messages.google.com/web)（把 Android 手機的簡訊同步到電腦） | 簡訊 |
| Messenger（messenger.com、facebook.com/messages） | 聊天訊息 |
| Telegram 網頁版、WhatsApp 網頁版 | 聊天訊息 |

- **很可能是詐騙**（例如自稱監理站，連結卻不是 `mvdis.gov.tw`）：右上角跳出浮動警告，附上官方網址、正確繳費管道與一鍵通報；訊息加紅框，裡面的連結 2 小時內點了一律攔截。
- **可疑**（例如沒有連結，但要你把驗證碼傳給他）：只在訊息上加橘色外框，滑鼠移上去看說明。朋友之間常互傳各種連結，所以不跳警告。
- 工具列視窗會顯示「正在自動檢查這個畫面上的訊息」；如果網站改版讀不到訊息，會顯示提示，請改用貼上檢查。

訊息內容只在你的電腦上判斷，不會上傳。各網站的版面對應寫在 `src/adapters/message-sites.js`，一個網站一筆設定。開發時只能用模擬頁面測試，沒有登入真實帳號驗證；沒有顯示警告時請回報。LINE 沒有網頁版，請用手機「分享」或貼上檢查。

## 網頁信箱（Gmail、Outlook、Yahoo）

在 Gmail、Outlook、Yahoo 網頁信箱開信時，插件會讀取主旨、寄件人信箱、內文與連結的真正網址（不是顯示的文字），判斷為詐騙或可疑時，在信件上方顯示警告，並提供「改到官方網站查詢」「一鍵通報」「回報誤判」。

這個功能依賴各信箱網頁的版面結構。開發時只能用模仿 Gmail、Outlook 版面的模擬頁面測試，沒有登入真實信箱驗證；信箱改版後可能需要更新（`src/adapters/message-sites.js`）。沒有顯示警告時，仍可把信件內容貼到工具列視窗或手機網頁檢查。

## 信件能擋到什麼程度

| 方式 | 擋在哪個階段 | 說明 |
|---|---|---|
| Gmail 收件匣過濾 | 信進到收件匣後幾分鐘 | 詐騙信加標籤並移出收件匣，你根本不會在收件匣看到它。詳見 [gmail/README.md](gmail/README.md) |
| 擴充功能：網頁信箱 | 開信時 | 在信件上方顯示警告，信裡的可疑連結加紅框 |
| 擴充功能：點連結 | 點下連結時 | 被判定為詐騙的信，信裡的連結 2 小時內點了一律攔截；單看網址看不出問題的連結（`yarlgs.com`）也一樣 |
| 簡訊檢查網頁、工具列視窗 | 點開前 | 把信件內容貼上檢查 |

瀏覽器擴充功能沒有權限存取信箱伺服器，所以不能刪除或移動信件；要在信進來時就處理，需要用 Gmail 收件匣過濾。

## 官方網站清單（446 個機構）

- `.go.jp`、`.lg.jp` 和 `.gov.tw` 一樣視為政府網域（只有日本政府機關能申請）。
- 每個網域都必須出現在 Chrome 台灣（日本品牌用日本）熱門網站資料中才收錄（`tools/verify-domains.mjs`），避免收錄記錯或不存在的網域。這個檢查只能證明「網域存在而且很多人用」，不能證明「屬於誰」，名稱對應仍需人工確認。
- **線上更新**：插件每天從本專案網站下載最新官方清單，修正誤判不用等插件改版。為了防止 repo 被入侵時有人把詐騙網域標成官方，下載的清單必須通過以下檢查，否則沿用內建版本：
  - 不能含有涉詐清單或使用者封鎖清單上的網域。
  - 不能含有網域後綴本身（`com.tw`）或整個架站平台（`github.io`）。
  - 機構數必須在合理範圍內。
  - 一次最多新增 300 個網域。

## 手機版簡訊檢查網頁

`web/index.html` 是單一檔案，判斷引擎和擴充功能是同一份程式碼，全部在手機上執行，不傳送任何資料。可以放到任何靜態網站（例如 GitHub Pages），或直接用瀏覽器開啟。修改引擎或清單後，執行 `node tools/build-web.mjs` 重新產生。

### 安裝成手機 App，從簡訊直接「分享」過來

- **Android**：用 Chrome 開啟[檢查網頁](https://judylin0324.github.io/official-url-guard/)，選單 →「加到主畫面」或「安裝應用程式」。之後在簡訊或 LINE 長按訊息 →「分享」→「官網守門員」，直接顯示檢查結果，不用複製貼上。
- **iPhone**：用 Safari「加入主畫面」後可以像 App 一樣開啟，但 iPhone 不支援分享到網頁 App，仍要貼上。
- 安裝後沒有網路也能檢查。分享過來的訊息只在手機上判斷，網址列裡的訊息內容會立刻清掉，不留在瀏覽紀錄。
- 其他程式也可以用網址帶入訊息：`https://judylin0324.github.io/official-url-guard/?text=訊息內容`。

手機網頁只能「先檢查再點開」，無法像擴充功能那樣自動攔截。

## 和 Chrome 內建「安全瀏覽」的差別

Chrome 的增強型防護很好，**建議兩個一起開**，彼此互補。

| | Chrome 安全瀏覽 | 官網守門員 |
|---|---|---|
| 判斷方式 | 黑名單＋AI，判斷「這是不是壞網站」 | 白名單，判斷「這是不是官方網站」，並比對網頁或簡訊內容與網址 |
| 剛架好幾小時的新詐騙網站 | 可能還沒收錄 | 不需要事先知道這個網址：頁面或簡訊自稱政府，網址卻不是 `.gov.tw`，就會警告 |
| 告訴你真的官網在哪 | 否 | 是 |
| 台灣在地 | 一般 | 165 清單、台灣銀行／政府／電商、運動幣、賣貨便、EZ WAY 等在地名目 |
| 通報 | 回報給 Google | 一鍵開啟網詐通報查詢網並帶入網址 |
| 隱私 | 增強型防護會把網址送給 Google 即時檢查 | 全部在本機判斷 |

### 網域名稱小模型

很多詐騙網址是隨機名稱（`npvgxc.shop`、`emord.top`），規則抓不到。小模型只看網域名稱的拼法（字元組合、長度、母音比例），在本機計算，約 11 KB。

- 訓練：2025/7 以前通報的詐騙網域（TWNIC、165），加上 Chrome 台灣熱門網站前 10 萬名的八成。
- 測試：2025/7 以後的新詐騙網域，加上熱門網站另外兩成（訓練時完全沒看過）。

| 只用沒看過的資料 | 沒有模型 | 有模型 |
|---|---|---|
| 2025/7 以後的 TWNIC 新詐騙（700 個）：至少提醒 | 48.0% | 49.3% |
| 2025/7 以後的 165 假投資（4,181 個）：至少提醒 | 10.4% | 11.9% |
| 熱門網站中沒看過的兩成：誤判為危險 | 0.1% | 0.1%（不變） |

效果不大，但不增加「危險」誤判，所以採用。模型分數最多 25 分，單獨不會觸發警告，只會讓已經有其他可疑特徵（例如 `.shop` 後綴）的網址升為「可疑」。前 5 萬名熱門網站中因此多了 18 個「可疑」，看起來幾乎都是隨機字母的 `.shop` 一頁式商店。重跑：`node tools/train-model.mjs <資料夾>`（加 `--write` 才會覆寫模型）。

怎麼解讀：

- 只看網址，大約能對四成的真實詐騙網址提出警告。其餘多半是隨機網域名稱（`emord.top/item/…`），要靠網頁內容判斷（一頁式購物、要求信用卡的頁面），或靠涉詐清單攔截。
- 開啟預設的清單自動更新後，165 與 TWNIC 清單上的 3 萬多個網域會直接攔截。
- 台灣熱門網站中，約 0.6% 會被標為「可疑」，多半是因為使用 `.top`、`.shop` 這類詐騙常用後綴。只因後綴被判可疑時，只亮工具列的橘色徽章，不會跳出提示列。
- 熱門網站清單排名越後面，越可能本身就是詐騙網站，所以誤判數字是保守估計。

資料來源：TWNIC 停止解析清單（[Taiwan-Blocked-Domains](https://github.com/lf94878964/Taiwan-Blocked-Domains)）、165 假投資網站（[g0v 鏡像](https://github.com/g0v-data/165-data)）、2026/9 Chrome 台灣熱門網站（[crux-top-lists-country](https://github.com/InternetHealthReport/crux-top-lists-country)）、標註訊息案例（[message-unpacked](https://github.com/batterycat/message-unpacked)，Apache-2.0）。重跑方式見下方「開發」。

## 已知限制

- 簡訊與通訊軟體網頁版的自動檢查只用模擬頁面測試過，還沒有在真實帳號上驗證；網站改版後可能失效（見「簡訊與通訊軟體網頁版」）。
- 手機上的 Chrome 不支援擴充功能。手機請用簡訊檢查網頁，但它只能檢查、不能自動攔截。
- 官方清單需要維護。不在清單上不代表是詐騙，只是「無法確認是官方」。合法網站被提醒時，按「信任此網站」即可。
- 通報網站的自動填入是依常見欄位名稱尋找「網址」欄位。開發時無法連上真實的通報網站驗證，若沒有自動填入，請直接貼上（說明已在剪貼簿）。
- 只看網址時，約四成真實詐騙網址會被提醒；其餘要靠網頁內容判斷或涉詐清單。
- 內政部官方 165 下載網址只接受台灣網路連線，開發時無法驗證；台灣以外會自動改用 g0v 鏡像。
- 簡訊判斷以繁體中文為主，英文詐騙訊息辨識有限。
- 網頁信箱的自動檢查只用模擬頁面測試過，信箱網頁改版後可能失效（見「網頁信箱」）。
- 日文、英文訊息只涵蓋常見詐騙用語，辨識能力不如繁體中文。
- 讀不到圖片裡的文字。詐騙頁把機構名稱做成圖片時，靠網址、抄襲官網的痕跡、Logo 比對判斷；也讀不到不同網域 iframe 裡的欄位。
- QR Code 解碼器處理的是網頁上清晰、正面的 QR Code；用相機斜拍的照片解不出來（有內建 BarcodeDetector 的電腦，例如 macOS，會先用內建的）。台灣 Pay（TWQR）只辨識格式，不解讀轉入帳號等欄位（找不到公開的欄位規格）。
- Logo 指紋由 GitHub Actions 每週建立。第一次執行（2026/11/5）取得 297 個機構、733 個指紋；但 GitHub 的機器在國外，約 100 個台灣政府與銀行網站（例如監理服務網、遠通電收、台電、健保署）擋國外連線，抓不到它們的圖示。可以在台灣的電腦上執行一次補齊，之後每週更新會沿用：
  ```bash
  npm install --no-save playwright@1.63.0 && npx playwright install chromium && node tools/build-logo-hashes.mjs
  ```
  執行後把 `src/data/logo-hashes.js` 提交到 GitHub 即可。官方網站改版換 Logo 時，最慢一週後更新。
- 裝置端 AI 需要 Chrome 內建 AI 模型（較新版 Chrome、足夠的硬體與儲存空間），不是每台電腦都能用。開發時沒有真實模型可用，只用模擬的模型測試「怎麼使用 AI 的回答」；真實模型判讀中文網頁的準確度未經驗證，所以只當加分項，分數也比關鍵字低。
- 偷傳卡號偵測只看網頁主框架裡打的卡號，以及常見的傳送方式；用 Web Worker、另開視窗等方式傳送的看不到。
- 「送出前確認」靠按鈕文字（送出、確認、付款、下一步…）和表單送出事件辨識，少數自製按鈕可能認不出來。
- 通報截圖只截目前畫面看得到的部分。
- 這是輔助工具，不保證攔截所有詐騙。有疑問請撥 **165**。

## 隱私

所有判斷都在你的裝置上完成，不會上傳瀏覽紀錄或你輸入的內容。打字時的卡號、身分證判斷只產生「是／否」，內容不離開網頁。

會連網的只有：

- 每天下載一次涉詐網域清單與官方網站清單（GitHub、本專案網站、內政部；只是下載檔案，不附帶任何瀏覽資料）。可在設定頁關閉。
- 你主動按下「回報誤判／漏判」時，開啟本專案的 GitHub Issues 頁面；送出前可以修改或取消。
- 你按下「查註冊日期」，或在設定頁開啟自動查詢時（預設關閉）：只把網域名稱送到 rdap.org，不送完整網址。

網頁上的 QR Code、網站圖示與 Logo 在你的電腦上解碼、比對；網頁從別的網站載入的圖片，背景會不帶 Cookie 再下載一次圖片本身來解碼。裝置端 AI 在你的電腦上執行，網頁內容不會上傳。

偷傳卡號的偵測在網頁裡比對，卡號只存在那段程式的記憶體裡，回報給擴充功能的只有「傳到哪個網站」和「是不是還沒按送出」。通報截圖存在你電腦的下載資料夾（「官網守門員通報截圖」，系統不支援中文檔名時為 `OfficialUrlGuard-report`），不會上傳。

### 新增官方網站時

1. 到該機構官方公告或 165 全民防騙網確認網域，並用 `tools/verify-domains.mjs` 核對網域存在。
2. 在 `src/data/official-sites.js` 加一行；網域是一般英文單字（例如 `family`）時加 `generic: true`；跨國品牌加 `global: true`。
3. 執行 `npm test`，確認正常網站語料沒有新增誤判；有真實資料時再跑 `tools/eval-real.mjs` 看熱門網站誤判數。
