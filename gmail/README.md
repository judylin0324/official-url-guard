# Gmail 收件匣過濾

瀏覽器擴充功能只能在你「打開信、點連結」時警告；這個工具則是在詐騙信**進到收件匣後的幾分鐘內**就把它移走。

它是一段 Google Apps Script，在**你自己的 Google 帳號裡**執行，每 10 分鐘檢查一次新信：

| 判斷結果 | 處理方式 |
|---|---|
| 疑似詐騙 | 加上「官網守門員/疑似詐騙」標籤，移出收件匣（不會刪除，點左側標籤就找得到） |
| 有可疑之處 | 加上「官網守門員/請小心」標籤，留在收件匣 |
| 其他 | 不動 |

判斷方式和擴充功能相同：寄件人網域、信件自稱的機構和連結網址是否一致、看不見的藏字、拆開的品牌名、轉址連結、165／TWNIC 涉詐網域清單等。

## 安裝（約 3 分鐘）

1. 用要保護的 Gmail 帳號登入，打開 <https://script.google.com>，按「**新專案**」。
2. 把左側的 `程式碼.gs`（或 `Code.gs`）內容全部刪掉，貼上 [`Code.gs`](https://judylin0324.github.io/official-url-guard/gmail/Code.gs) 的內容。
3. 按左側「檔案」旁的 **＋ → 指令碼**，命名為 `Engine`，貼上 [`Engine.gs`](https://judylin0324.github.io/official-url-guard/gmail/Engine.gs) 的內容。
4. 按上方的 💾 儲存，專案名稱可以取「官網守門員」。
5. 上方函式選單選 `install`，按「**執行**」。
6. 第一次執行會要求授權：
   - 按「審查權限」，選你的帳號。
   - 會看到「**Google 尚未驗證這個應用程式**」：這是因為這段程式是你自己的專案，沒有送 Google 審查。按「進階」→「前往『官網守門員』（不安全）」。
   - 確認權限：讀取與管理 Gmail（判斷信件、加標籤）、連線到外部服務（下載 165／TWNIC 清單）、在你未使用時執行（定時檢查）。按「允許」。
7. 執行完成後，下方「執行記錄」會顯示「檢查 N 封：疑似詐騙 …」。之後每 10 分鐘會自動檢查。

## 調整與移除

- 設定在 `Code.gs` 最上方的 `SETTINGS`：
  - `SCAM_ACTION`：`'archive'`（預設，移出收件匣）、`'spam'`（移到垃圾郵件）、`'label'`（只加標籤，不移動）
  - `SCAN_MINUTES`：檢查間隔（1、5、10、15、30 分鐘）
- 移除：函式選單選 `uninstall` 執行，定時檢查就會停止（已加上的標籤會保留）；或直接刪除整個專案。
- 被誤判的信：到「官網守門員/疑似詐騙」標籤裡，把信移回收件匣，並在擴充功能或 GitHub 回報誤判，幫助改進。

## 隱私

- 程式在你的 Google 帳號裡由 Google 執行，信件內容不會傳到任何第三方，也沒有本專案的伺服器。
- 唯一的對外連線是下載公開的涉詐網域清單（GitHub 上的 TWNIC、165 鏡像）；不會附帶你的任何資料。可把 `USE_SCAM_LISTS` 改成 `false` 關閉。
- 程式碼全部公開，可以自行檢查。

## 限制

- 開發時在模擬 Gmail 環境中測試（模擬的信箱、標籤、觸發器；沒有瀏覽器 URL 功能，和 Apps Script 相同），尚未在真實 Gmail 帳號長期執行驗證。第一次安裝後，建議看一下「執行記錄」與標籤結果。
- Gmail 免費帳號的 Apps Script 每天有執行次數與時間上限；每 10 分鐘檢查一次遠低於上限。
- 只處理 Gmail。Outlook、Yahoo 信箱請用瀏覽器擴充功能在開信時警告。
